# TASK_000 — Environment Preparation

Перед началом любой новой функциональности подготовь проект к дальнейшей разработке.

Обязательно прочитай:

- CLAUDE.md
- PROJECT_CONSTITUTION.md
- ARCHITECTURE.md
- PROGRESS.md

Цель этой задачи — привести репозиторий и окружение в полностью корректное состояние.

До завершения TASK_000 не изменяй код проекта и не начинай TASK_002.

------------------------------------------------------------

ПЕРЕД НАЧАЛОМ

Обязательно прочитай:

- CLAUDE.md
- PROJECT_CONSTITUTION.md
- PROGRESS.md

------------------------------------------------------------

1. ПРОВЕРЬ СОСТОЯНИЕ REPOSITORY

Выполни:

git status

Проанализируй текущее состояние рабочей директории.

Если существуют незакоммиченные изменения,
относящиеся к завершённому Phase 1
(Learning Engine, Web UI, Engine API,
DexieStore, тесты, документация и т.д.),

не смешивай их
с будущими изменениями TASK_002.

------------------------------------------------------------

2. ЗАФИКСИРУЙ PHASE 1

Если Phase 1 ещё не закоммичен:

создай отдельный commit.

Commit должен содержать
ТОЛЬКО фундамент Learning Engine
и связанные с ним изменения.

Сообщение commit должно ясно отражать,
что фиксируется завершение первого этапа.

После commit покажи:

• hash commit

• сообщение commit

------------------------------------------------------------

3. ПРОВЕРЬ СОСТОЯНИЕ NPM

Определи:

• текущего пользователя

• UID

• GID

• владельца ~/.npm

Если права уже корректны —

ничего не изменяй.

Если обнаружены неверные владельцы
или права доступа —

попытайся исправить проблему.

Если исправление требует sudo
или участия пользователя —

не используй временный npm cache
как постоянное решение.

Остановись
и сообщи точную команду,
которую должен выполнить пользователь.

Не скрывай проблему.

------------------------------------------------------------

4. ПРОВЕРЬ ОКРУЖЕНИЕ

После исправления выполни:

npm install

npm test

Убедись,

что:

✓ используется обычный npm cache

✓ временный cache больше не нужен

✓ тесты проходят

------------------------------------------------------------

5. ПРОВЕРЬ СОСТОЯНИЕ ПРОЕКТА

Убедись,

что:

✓ рабочая директория чистая

✓ Phase 1 полностью зафиксирован

✓ окружение готово

Не начинай TASK_002.
