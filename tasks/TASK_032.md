# TASK_032: Тренировка трудных слов

**Status: DONE.** В «Карточках» под фильтром «Трудные» появилась кнопка
«▶ Повторить трудные слова» с числом карточек. Она запускает отдельную
тренировку: слово → вспомнить → «Показать ответ» → самооценка → следующее.
Тренировка — дополнительная практика: **ничего не записывает**, не меняет
FSRS, интервалы, даты повторения, основную очередь, Review Log, статистику и
дневной лимит новых карточек. Результаты живут только в памяти текущей
тренировки. 441 тест зелёный.

## Цель

Одна цель: в любой момент потренировать трудные слова, не нарушая основной
алгоритм обучения.

## Слой задачи

**UI** (`apps/web`) — потребитель публичного API ядра только на чтение.
Engine, `StudySession`, FSRS, `EngineStore`, Review Log, Dexie, backup,
дневной лимит, навигация — не менялись. Решение владельца по вопросу из
TASK_031 («записывать ли ответы тренировки в Review Log»): **не записывать**.

## Поведение

- **Что тренируется.** Карточки активных заметок с `scheduling.lapses > 0` —
  тот же признак «трудного», что у фильтра «Трудные» и «Статистики». Если в
  слове забывалось только одно направление, тренируется только оно (обратная
  карточка показывается своей стороной, например «утро → la mañana»).
  Архивные — никогда.
- **Кнопка** видна только под фильтром «Трудные» и только при наличии
  карточек: «▶ Повторить трудные слова [6]» (+ подпись «Отдельная тренировка:
  расписание повторений не меняется»). Число — та же выборка, что загрузит
  тренировка. При нуле кнопки нет (не создаём неработающих кнопок).
- **Экран** — режим фокуса, как сессия: без нижней панели и кнопки настроек.
  Та же разметка и стили, что у сессии обучения (`card-panel`, «Показать
  ответ», пример и личная заметка — только после ответа, липкая панель
  оценок). Метка «забыто N раз» вместо состояния FSRS; надзаголовок
  «Тренировка · без влияния на расписание»; прогресс «1 из 6».
- **Самооценки** — «Не помню» / «С трудом» / «Помню» (клавиши 1 · 2 · 3;
  Пробел/Enter — показать ответ, затем «Помню»). Это не `Rating` FSRS и
  интервалов у кнопок нет. Правила клавиш — как в сессии (TASK_025): фокус на
  кнопке или поле, удержание клавиши и модификаторы не перехватываются.
- **Итог**: «Повторено», «Помню», «Затруднения» (+ разбивка «Не помню» /
  «С трудом» и список слов с затруднениями), кнопки «Повторить ещё раз» и
  «К трудным словам».
- **Досрочно**: «Завершить» — итог по уже оценённым («Завершено досрочно:
  пройдено 2 из 6»); если ни одной оценки не было — сразу назад к трудным
  словам. «Назад» браузера тоже выходит из тренировки.
- **Повторный запуск** перечитывает карточки (слово, убранное в архив между
  раундами, выпадает) и перемешивает порядок заново (Fisher–Yates).
- **Пустое состояние** («Трудных слов нет…») и ошибка загрузки (сообщение +
  «Повторить попытку») — с кнопкой «К трудным словам».

## Как обеспечена независимость от FSRS

1. `PracticeController` получает **только загрузчик карточек** — ни
   `LearningEngine`, ни `StudySession`. Записать ответ, сдвинуть `due` или
   изменить счётчик лимита ему нечем.
2. Единственное обращение к ядру — `loadDifficultPractice(engine)`, тип
   параметра `Pick<LearningEngine, 'listCardViews'>`: другие методы ядра
   недоступны на уровне типов.
3. Оценки тренировки — свой тип `PracticeGrade`, не `Rating`; результаты —
   массив в памяти контроллера, исчезает с экраном.
4. Тренировка не в адресе (как и сессия): состояние только в памяти `App`.

## Решения и почему

- **Один проход без повторов внутри раунда.** «Не помню» не возвращает
  карточку в конец очереди: тренировка короткая, а слова с затруднениями
  перечислены в итоге — «Повторить ещё раз» прогоняет все снова. Проще и
  предсказуемо; повтор внутри раунда можно добавить позже.
- **Три оценки, не четыре.** Итог различает «хорошо» и «затруднения»;
  отдельная «Легко» без влияния на расписание ничего бы не давала.
- **Кнопка только в «Карточках»**, куда ведут и Главная («Трудные слова»), и
  «Статистика» («Посмотреть слова»): один вход, без дублей.
- **Тренировка не в статистике.** Статистика — производная от Review Log;
  отдельный учёт тренировок — новая модель данных, не нужна для цели задачи.

## Известные ограничения

- Результаты тренировки не сохраняются (по требованию): после выхода их нет.
- Число на кнопке — карточки, а «Найдено» в списке — слова; при обратных
  карточках они могут различаться (подпись кнопки для экранных дикторов
  говорит «карточек»).
- Кнопка учитывает все трудные карточки, а не текущий поиск/теги.
