## Что сделано

**Структура токенов** (`styles.css`, начало файла):
1. `:root` — шкалы, не зависящие от темы: `--font-*`; типографика `--type-<role>-size/-line/-weight(/-tracking)` и `--type-<role>` (шорткат `font`) для 14 ролей DS; `--space-*`; `--radius-*`; размеры (`--tap-min`, `--control-h`, `--button-h(-lg)`, `--rating-h`, `--row-h`, `--nav-h`, `--icon`); движение (`--ease`, `--ease-in`, `--dur-1/2/3`).
2. `:root` — светлая палитра (все цвета и тени DS §1, §5).
3. Тёмная палитра — дважды (`data-theme="dark"` и медиа-запрос), как раньше.
4. `prefers-reduced-motion`: `--dur-*` → 0 ms (к прежнему правилу).

**Дополнения к DS** (существующие значения, получившие имена, — без новых цветов):
`--accent-light` (`#8b7cf8`, начало градиента полосы цели и знака),
`--on-accent-soft` (счётчик на кнопке тренировки), `--elev-control` (тень
бегунка переключателя), `--elev-accent` (свечение кнопки CTA и знака).

**Перевод правил на токены** (значение в значение, проверено вычисленными стилями):

| Что | Замен |
|---|---|
| `var(--text-muted)` → `var(--text-secondary)` | 45 |
| `var(--shadow-card)` → `var(--elev-2)`; тень панели → `--elev-nav` | 8 + 1 |
| `var(--radius)` → `var(--radius-md)`; литералы 8/12/16/22/999 px → `--radius-*` | 6 + 17 |
| `padding/margin/gap`: значения шкалы → `--space-*` | 134 |
| `font-size` совпадающих ролей → `--type-*-size` | 61 |
| `min-height/min-width: 44px` → `--tap-min` | 19 |
| `color: var(--danger)` → `--danger-text`; `--streak` → `--streak-text` | 8 + 1 |
| литеральные цвета/тени в правилах → токены | 9 |

Удалены старые имена `--text-muted`, `--shadow-card`, `--radius` (ни одной
ссылки не осталось — проверяется тестом). Литеральных цветов в правилах
компонентов — **ноль**.
