# TASK_038: Экран повторения и тренировка

**Status: DONE (код + тесты), ветка `docs/ui-ux-design`, без push и деплоя.**

повторения и тренировка трудных слов — фокус-режим с действиями в зоне
большого пальца и единым языком оценок из трёх кнопок (ADR-006).

## Первый шаг — ADR-006

`docs/adr/ADR-006-three-rating-buttons.md` (Accepted; индекс
`docs/adr/README.md`): интерфейс повторения предлагает три оценки
`again / hard / good` — «Не помню · С трудом · Помню»; `easy` остаётся в ядре

## Что сделано

**Логика** (`session-view.ts`, чистая): `SESSION_GRADES` (единый источник для
кнопок и клавиш), подписи и тона, `wordSize()` (≤ 18 / ≤ 40 / ≤ 80 символов →
xl / l / m / s по `--type-word-*`), счётчик «3 / 12», тексты экранов итога,
предложение «Тренировка трудных · N слов».

**Клавиши** (`review-hotkeys.ts`): `HOTKEY_RATINGS = SESSION_GRADES` — 1–3;
клавиша 4 ничего не делает; Пробел/Enter — как раньше.

**Компоненты** (`ui/`): `SessionHeader` (✕ · прогресс 4 px · счётчик ·
необязательная строка), `RatingBar` (кнопки одинаковой ширины, 64 px, мягкие
семантические заливки, интервал второй строкой, «нажатая» подсветка на время
записи), `ActionDock` (зафиксирован внизу над safe-area, контент уходит под
затухание; `ui-action-dock-space` — место под ним). `SessionSummary` —
шаблон экранов итога (бренд-знак градиентом, заголовок, числа, действия).

**Экран повторения** (`ReviewSession.tsx`):
- Без шапки ALSAVI (TASK_037); `SessionHeader` с «✕» («Завершить повторение», неактивна на время записи).
- Слово в центре верхней части (`max(180px, 36dvh)`), размер по длине; при показе ответа слово не сдвигается — ответ раскрывается ниже (разделитель, перевод 22 px, «Пример» и «Моя заметка» во вставках).
- Значок только «Новое слово» для новых карточек; FSRS-состояния убраны (R-4).
- Док: «Показать ответ» (64 px — как оценки, док не прыгает) → три оценки с настоящими интервалами `previewIntervals`; касание по слову тоже показывает ответ; подсказка «Пробел» / «1 · 2 · 3» только при точном указателе.
- Обратная связь: выбранная кнопка подсвечивается на время записи; новая карточка въезжает (160 мс, `transform/opacity`, выключается при reduced-motion). Ввод не ждёт анимации.
- Ошибка записи — `Banner` над оценками, карточка и выбор остаются (логика контроллера прежняя).
- `lang="es"` у испанской стороны: у прямой карточки — слово, у обратной — ответ.
- Итог: «Готово!», «Повторено N карточек», «Из них новых M», «Тренировка трудных · N слов» (если есть, число — `getLearningStats().difficult.total`), «На главную». Пустые экраны («Сегодня всё повторено», дневной лимит) — тот же шаблон.

**Тренировка** (`PracticeSession.tsx`): тот же шаблон и `RatingBar`, три
оценки без интервалов, строка «Тренировка · расписание не меняется» под
шапкой, значок «забыто N раз»; итог — три числа, слова с ошибками, досрочное
завершение, «Повторить слова с ошибками» / «Повторить ещё раз» / «К трудным
словам».

**App:** «Тренировка трудных» с итога сессии закрывает завершённую сессию и
запускает тренировку (иначе Главная показала бы итог снова); заглушки гейта
`bootstrap` — `Skeleton home` и `EmptyState` с «Повторить» вместо старых
`.card-panel`.

**CSS:** старые правила сессии и тренировки удалены парсером (47 селекторов:
`.card-panel`, `.state-badge*`, `.card-front/back`, `.answer-*`, `.hotkey-hint`,
`.session-progress*`, `.session-exit`, `.practice-*` кроме кнопки в
«Карточках»); новые — раздел TASK_038 в `styles.css` и компоненты в `ui.css`.

## Отклонения от спецификации

- **Действия экранов итога — в потоке под содержимым**, а не в фиксированном доке: у итога тренировки три кнопки и список слов — в доке они перекрывали бы список. Док — только для активной карточки, где важна мышечная память.
- **Подсветка нажатия** — на время записи ответа (обычно < 100 мс), без отдельного таймера: анимация не задерживает следующий ответ.
- **В аудите** источник горячих клавиш был указан как `apps/web/README.md` — на деле `tasks/TASK_022.md`; исправлено в `UI_UX_AUDIT.md` §5, а в README добавлен раздел о клавишах.
