# Цель

Реализовать первый законченный пользовательский сценарий ALSAVI:

```bash
ask --model llama3 --context-budget 20000 "What is spaced repetition?"
```

Полный путь:

```
CLI
    ↓
AIService.answer()
    ↓
Engine
    ↓
OllamaProvider
    ↓
ответ модели
    ↓
stdout
```

Это первая пользовательская точка входа ALSAVI.

Никакие новые транспортные слои (HTTP API, REST, GraphQL, WebSocket,
IPC, daemon, server mode) не вводятся.

CLI вызывает `AIService.answer()` напрямую внутри Node-процесса.

Команда должна быть доступна как локальный entry point монорепозитория.

Имя глобального bin (`alsavi` или иное), публикация npm и глобальная
установка НЕ являются предметом TASK_012.

# Архитектурные решения (приняты)

## Размещение

CLI располагается в

```
apps/cli
```

`packages/*` содержат библиотеки.

`apps/*` содержат приложения-потребители.

После реализации структура становится

```
apps/
    cli/
    web/
```

---

## Конфигурация

Конфигурация передаётся **только через аргументы CLI**.

Не использовать:

- dotenv;
- обязательные env;
- YAML;
- JSON;
- пользовательские config-файлы.

Поддерживаются только три параметра:

```
--model <name>
```

обязателен.

```
--context-budget <int>
```

обязателен.

Соответствует обязательному

```
contextBudgetChars
```

в `AIServiceOptions`.

Значение должно быть **положительным целым числом**.

```
--endpoint <url>
```

опционален.

Если флаг отсутствует,

**CLI**

использует

```
http://127.0.0.1:11434
```

при создании `OllamaProvider`.

Сам `OllamaProvider`
не содержит собственного значения endpoint по умолчанию.

---

## Парсер аргументов

Разбор аргументов выполняется вручную через

```
process.argv
```

Без внешних зависимостей.

Не использовать:

- commander;
- yargs;
- oclif;
- любые CLI-framework.

# Реализация

## Команда

```bash
ask [--endpoint <url>] --model <name> --context-budget <int> "<question>"
```

Один позиционный аргумент —

вопрос пользователя.

---

## Поведение (успешный сценарий)

CLI должен:

- разобрать аргументы;
- создать

```
OllamaProvider({
    endpoint,
    model
})
```

- создать

```
AIService({
    provider,
    contextBudgetChars
})
```

- вызвать

```
answer(question)
```

- вывести **ровно текст ответа модели** в stdout;
- завершиться кодом

```
0
```

Никаких:

- баннеров;
- логов;
- "Connecting...";
- "Thinking...";
- цветного вывода;
- служебных сообщений.

---

## Ошибки

### Ошибка аргументов

Если:

- отсутствует `--model`;
- отсутствует `--context-budget`;
- бюджет не является положительным целым числом;
- отсутствует вопрос;

CLI:

- печатает понятную ошибку в stderr;
- завершает работу с кодом ≠ 0;
- НЕ создаёт AIService.

---

### ContextBudgetExceededError

Показать пользователю:

```
actualChars
budgetChars
```

Код возврата

```
≠ 0
```

---

### Runtime-ошибки

Например:

- ECONNREFUSED;
- Ollama не запущена;
- timeout;
- network failure.

CLI:

- выводит runtime-ошибку;
- завершает работу с кодом ≠ 0.

CLI НЕ должен:

- автоматически запускать Ollama;
- выполнять retry;
- менять endpoint;
- выполнять какие-либо автоматические действия.

# Definition of Done

1. Создан `apps/cli`.

2. Возможен локальный запуск CLI внутри монорепозитория.

3. Используется существующий публичный API `@alsavi/ai`.

4. AI Layer не изменён.

5. Engine не изменён
   (пустой diff в exports Engine).

6. `--model`
   и
   `--context-budget`
   обязательны.

7. `--endpoint`
   опционален.

   При отсутствии флага
   **CLI**
   передаёт в `OllamaProvider`

```
http://127.0.0.1:11434
```

8. Неверные аргументы →

- stderr;
- код ≠ 0;
- AIService не создаётся.

9. `ContextBudgetExceededError`
   корректно отображается пользователю.

10. Недоступность Ollama
    пробрасывается как runtime-ошибка.

    Нет:

- retry;
- автозапуска;
- подмены endpoint.

11. Добавлены CLI unit-тесты:

- разбор аргументов;
- маппинг флагов в конфигурацию;
- коды возврата;
- обработка ошибок;
- **при отсутствии `--endpoint` CLI передаёт в `OllamaProvider`
  `http://127.0.0.1:11434`.**

12. Все HTTP полностью мокируются.

13. Ни один тест не требует работающей Ollama.

14. CI полностью детерминирован.

15. Все существующие тесты проходят:

- engine;
- anki-import;
- backup;
- ai.

16. Обновлены:

- ARCHITECTURE.md;
- PROGRESS.md.

17. Один отдельный коммит.

18. Push НЕ выполнять.
