# TASK_030: Новый интерфейс — этап 3: нижняя навигация и «Профиль»

**Status: DONE (коммит — см. `PROGRESS.md`; деплой — по решению владельца).**
Четыре раздела — Главная, Карточки, Статистика, Профиль — в единой навигации:
плавающая панель внизу на телефоне, строка вкладок на компьютере. Новый экран
«Профиль» собрал настройки и данные. Строка статистики под шапкой убрана.
У каждого раздела есть адрес (`#/cards`, `#/stats`, `#/profile`). В сессии —
режим фокуса с кнопкой «Завершить». 402 теста зелёные (+11).

## Цель

Одна цель: единая навигация по четырём разделам, одинаковая на всех экранах,
с фирменной шапкой ALSAVI сверху.

## Слой задачи

**Только UI** (`apps/web`). Engine, `StudySession`, FSRS, Review Log,
`EngineStore`, схема IndexedDB, backup-формат, проверка и сохранение
дневного лимита (TASK_020) — **не менялись**. Порядок этапов поменян по

подтвердил переход к этапу 3 после этапа 2.

## Что сделано

**Навигация** (`MainNav.tsx`, `nav.ts`).
- Один элемент `<nav aria-label="Разделы">`, четыре кнопки с иконками и
  подписями, `aria-current="page"` у текущей. Телефон: плавающая
  «стеклянная» панель над индикатором «Домой» (safe-area; без
  `backdrop-filter` — просто непрозрачная), цели 52 px. Компьютер: ≥ 900 px —
  строка вкладок под шапкой; ≥ 1100 px — в строке шапки по центру (там, где
  она помещается между логотипом и кнопками).
- Адреса: `#/cards`, `#/stats`, `#/profile`, Главная — без hash. Работают
  прямые ссылки, перезагрузка, «Назад»/«Вперёд» браузера; повторное нажатие на
  текущий раздел не добавляет запись в историю; неизвестный адрес открывает
  Главную. Hash не уходит на сервер — ничего не меняется для GitHub Pages
  (`/ALSAVI/`) и офлайн-режима PWA. Адресуется только раздел: сессия,
  фильтры и фокус в адрес не попадают. При смене раздела страница
  прокручивается к началу.
- Вкладки-переключатель под шапкой (этап 2) и строка статистики удалены.
  Числа строки статистики уже есть на экранах: очередь и ответы сегодня — на
  Главной, серия — в шапке, всего карточек — на плитке «Мои карточки» и в
  «Статистике». Без своего места осталась только общая точность за всё время —
  кандидат для этапа 4.

**Режим фокуса в сессии.** Во время сессии нет нижней панели и кнопки
настроек (как и на этапе 2): цифры 1–4 и пробел принадлежат сессии. В строке
прогресса добавлена кнопка «Завершить» → Главная (неактивна, пока ответ
сохраняется). Выход ничего не записывает; `StudySession` живёт в `App`, поэтому
«Продолжить обучение» продолжает ту же очередь. Раньше выйти из сессии до её
конца было нельзя (вкладки сверху оставались, но не уводили из сессии).

**«Профиль»** (`ProfileScreen.tsx`). Аккаунта нет — экран честно говорит, что
данные хранятся только на этом устройстве. Три раздела:
- «Обучение» — «Новых карточек в день» (пусто — без ограничения): поле
  нормальной ширины (известная проблема TASK_027 о поле ~18 px снята),
  сохранение по уходу из поля и теперь по Enter. Пока сохранённый лимит не
  загружен, поле неактивно: пустое поле означает «без ограничения», и
  сохранить его до загрузки значило бы затереть настоящий лимит (раньше в
  «Карточках» такая гонка была возможна).
- «Оформление» — тема «Как в системе / Светлая / Тёмная» (переехала из окна
  настроек этапа 2).
- «Данные» — импорт из Anki, экспорт, восстановление. Код и тексты перенесены
  из блока «Инструменты» «Карточек» без изменений (`backup-messages.ts`,
  `restoreBackup` с подтверждением, отчёт импорта); после импорта и
  восстановления обновляется серия в шапке, а список «Карточек» перечитывается
  при следующем открытии раздела.
- Кнопка «Настройки» в шапке открывает «Профиль». Окно настроек
  (`SettingsSheet.tsx`) удалено — его содержимое теперь в «Профиле».

**«Карточки»** стали короче: блок «Инструменты» уехал в «Профиль»; у
`CardManager` остались только список, форма и архив (пропсы лимита и
хранилища убраны). Текст пустого списка ссылается на Главную вместо
«Учиться сегодня».

## Решения и почему

- **Адреса через hash, без библиотеки маршрутизации.** Четыре раздела — это
  функция в 40 строк с тестами; hash не требует настройки сервера GitHub Pages
  и работает офлайн. Сессия в адрес не попадает: её состояние живёт в памяти
  `StudySession`, и ссылка на «середину сессии» не имела бы смысла.
- **Один элемент навигации, раскладка — CSS.** Нет двух копий кнопок для
  телефона и компьютера; порядок фокуса одинаковый: шапка → разделы →
  содержимое.
- **Режим фокуса в сессии.** Панель внизу конфликтовала бы с липкими кнопками
  оценки; без неё нужен явный выход — «Завершить».
- **«Профиль» без выдуманного аккаунта.** Аккаунтов нет и не планируется до
  Beta; экран называет то, что есть: настройки и данные этого устройства.
