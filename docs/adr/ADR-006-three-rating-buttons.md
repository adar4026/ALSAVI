# ADR-006 — Three rating buttons in the review interface

**Статус:** Accepted · TASK_038 (решение владельца 2026-11-14, `docs/ui-ux/UX_DECISIONS.md` Q1 / D-06)

## Context

FSRS оценивает ответ одной из четырёх оценок (`Rating`: `again`, `hard`,
`good`, `easy`). До TASK_038 основная сессия повторения показывала все четыре
кнопки — «Не помню / Трудно / Хорошо / Легко», а тренировка трудных слов
(TASK_032, без записи в Review Log) — три: «Не помню / С трудом / Помню».
Аудит интерфейса (`docs/ui-ux/UI_UX_AUDIT.md`, R-2, R-3) показал два языка
для одного действия «оценить себя», и на 375–390 px «Не помню» в четырёх
колонках переносилось на две строки. Бриф владельца описывает экран повторения
с тремя кнопками.

Это не оформление: набор кнопок определяет, какие оценки получает
планировщик, то есть входной сигнал алгоритма памяти. Поэтому — ADR.

## Options

- **A. Четыре кнопки, новые подписи** «Не помню · С трудом · Помню · Легко».
  Полный сигнал FSRS; цена — четыре решения на каждой карточке и узкие кнопки.
- **B. Четыре кнопки, подписи как были.** Ничего не меняется; два языка
  оценок остаются.
- **C. Три кнопки** `again / hard / good` — «Не помню · С трудом · Помню», и в
  сессии, и в тренировке. Проще и один язык; цена — нет `easy`.

## Decision

Выбран **вариант C** (владелец, 2026-11-14).

- Интерфейс повторения предлагает три оценки: «Не помню» → `again`,
  «С трудом» → `hard`, «Помню» → `good`. Клавиши: 1–3; Пробел/Enter после
  показа ответа = `good` (как раньше); клавиша 4 ничего не делает.
- Тренировка трудных слов использует тот же компонент и те же подписи
  (без интервалов — она ничего не записывает).
- **Не меняются:** `Rating` (четыре значения), `Scheduler`/FSRS,
  `LearningEngine.review()`, `ReviewFlowController`, `StudySession`, Review
  Log, бэкап, импорт Anki, CLI. `easy` остаётся допустимой оценкой ядра для
  других потребителей (CLI, импорт, будущие режимы).

## Consequences

**Плюсы:**
- Один язык самооценки в сессии и тренировке; меньше решений на карточку.
- Кнопки шире (≈ 93 px на 320 px, ≈ 111 px на 375 px) — подписи в одну
  строку, удобнее одной рукой.
- Нет миграций и изменений данных: старые ответы `easy` в журнале остаются
  валидными и, как и прежде, считаются успешными в статистике.

**Минусы / цена:**
- Хорошо известные слова растут в интервалах только через `good`, поэтому
  повторений будет немного больше, чем при регулярном «Легко».
- Новая карточка всегда проходит шаги изучения (`easy` пропускал их).
- Распределение оценок в журнале смещается к `good` — учитывать при будущем
  анализе/оптимизации параметров FSRS.

**Обратимость:** вернуть кнопку — изменение набора оценок в UI
(`apps/web/src/session-view.ts` и `review-hotkeys.ts`); ядро и данные готовы.

**Проверка:** тесты `session-view.test.ts` (три оценки, без `easy`),
`review-hotkeys.test.ts` (клавиша 4 не записывает ответ),
`review-flow.test.ts` без изменений (запись `again/hard/good` прежняя).
