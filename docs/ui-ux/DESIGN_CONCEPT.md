# Визуальная концепция ALSAVI — «Тихий фокус»

**Эволюция, а не смена облика.** Фиолетовый акцент, холодный светлый фон,
скруглённые поверхности и плавающая панель остаются — это уже узнаваемый
ALSAVI. Меняется дисциплина: одна шкала размеров, одна иерархия на экран,
действия у большого пальца, слово — главный объект.

Опора: `PROJECT_CONSTITUTION.md` → DESIGN («Минимализм. Максимум воздуха.
Максимум читаемости. Никакого визуального шума. Сначала удобно, потом
красиво») и LEARNING PRINCIPLES («Красивый интерфейс никогда не должен
ухудшать эффективность обучения»).

---

## 1. Принципы

1. **Одно главное действие на экран.** Главная — «Начать»; сессия —
   «Показать ответ» / оценка; Карточки — найти; Статистика — понять; Профиль —
   настроить. Всё прочее визуально тише.
2. **Слово — герой.** На экране обучения нет хрома, кроме прогресса и выхода.
   Испанский текст — самый крупный и контрастный элемент приложения.
3. **Зона большого пальца.** Повторяющиеся действия — в нижних 40 % экрана,
   на фиксированных местах (мышечная память).
4. **Честные числа, один словарь.** *Слово* — то, что пользователь добавил;
   *карточка* — направление повторения. Каждое число с единицей и одним
   определением во всём приложении.
5. **Цвет — это смысл.** Фиолетовый — только действие, выбор и прогресс.
   Красный/янтарный/зелёный — только оценка памяти и статусы. Остальное —
   нейтрали.
6. **Движение — это обратная связь.** Анимация отвечает на действие
   (нажатие засчитано, карточка ушла, лист открылся), не украшает. Всегда
   ≤ 240 мс, всегда отключается `prefers-reduced-motion`.
7. **Разные экраны — разная форма.** Не «стопка одинаковых белых карточек»:
   Главная — герой + плитки; сессия — полотно без рамок; Карточки — плотный
   список; Статистика — дашборд; Профиль — сгруппированный список настроек.

---

## 2. Что сохраняем, улучшаем, перерабатываем

### Сохранить без изменений
- Акцент `#6d5df6` и его тёмная пара; фон `#f6f6fb` / `#0f1115`.
- Четыре раздела и плавающая «стеклянная» панель на телефоне.
- Фокус-режим сессии (навигация скрыта), блокировка на время записи.
- Все защиты ввода (черновик, дубль, подтверждения, undo архива).
- Честные пустые состояния и ошибки с «Повторить».
- Тема «Система / Светлая / Тёмная» без вспышки при старте.
- Системный шрифт (SF Pro на iPhone) — без веб-шрифтов: офлайн и скорость.
- Горячие клавиши сессии и их логика (`review-hotkeys.ts`).

### Улучшить
- Шкалы: типографика (9 ступеней вместо 15 размеров), отступы (сетка 4 px),
  радиусы (5 значений вместо 13), тени (2 уровня).
- Главная: меньше текста, одно крупное число, полезные действия при пустой
  очереди.
- Статистика: одно определение очереди, герой «изучено слов», подписи с
  единицами.
- Профиль: сгруппированный список, короче тексты.
- Шапка: настоящий логотип, бренд только на Главной, крупные заголовки
  разделов.
- Состояния: скелетоны вместо пустых блоков, тосты вместо разрозненных
  уведомлений.

### Переработать
- **Экран повторения**: нижний док действий, единый `RatingBar` с цветами,
  адаптивный размер слова, итог-экран.
- **Раздел «Карточки»**: список — основной вид; просмотр карточки — новый
  экран; добавление/редактирование — лист.
- **Библиотека компонентов**: свести дубли (4 вида панелей, 2 сегмента,
  2 прогресс-бара, 2 иконки-кнопки).

## 3. Цвет

Палитра — эволюция токенов TASK_029 (значения в
[DESIGN_SYSTEM](DESIGN_SYSTEM.md) §1).

- **Бренд.** `--accent #6d5df6` остаётся основным. Логотип (тёмно-синий фон,
  карточки сине-фиолетово-коралловые) задаёт **бренд-градиент**
  `#4f7cff → #6d5df6 → #ff7a59` — используется *только* в бренд-моментах:
  знак на Главной, экран завершения сессии, иконка. В интерфейсе — никогда
  как фон кнопок.
- **Нейтрали** — холодные, с лёгким фиолетовым оттенком (как сейчас), шкала
  из 6 ступеней поверхности и 3 ступеней текста.
- **Память (семантика оценок):** «Не помню» — коралл-красный, «С трудом» —
  янтарь, «Помню» — зелёный (три оценки — решение владельца, D-06). В кнопках — мягкие
  заливки (soft) + цветной текст; насыщенный цвет — только в нажатом
  состоянии и в графиках. Почему не фиолетовый для «Помню»: акцент не должен
  подталкивать к одной оценке (Desirable Difficulties: оценка должна быть
  честной).
- **Серия** — оранжевый пламени `--streak` (перекликается с кораллом логотипа).
- **Контраст** — всё ≥ WCAG AA (текст 4.5:1, крупный 3:1, нетекстовые 3:1).

### Светлая тема
Фон `#f6f6fb`, поверхности белые, разделение — тонкая граница + очень мягкая
тень у героя. Акцент насыщенный.

### Тёмная тема
Не инверсия: фон `#0f1115`, поверхности поднимаются светлотой (`#171a22` →
`#1f2330` → `#2a2f3d`), тени почти не используются, границы `#2a2e3a`.
Акцентный текст светлее (`#ab9ffb`), заливки оценок — 14 % альфа. Испанское
слово — `#f3f2fa`, не чисто белый (меньше ореола на OLED).

## 4. Типографика

Системный стек: `-apple-system, "SF Pro Text", "SF Pro Display", "Segoe UI",
Roboto, sans-serif`; для крупных чисел — `ui-rounded` (SF Pro Rounded на
Apple, иначе системный) — мягкие, дружелюбные цифры без загрузки шрифта.
Все числа — `font-variant-numeric: tabular-nums`.

| Роль | Размер / строка / вес | Где |
|---|---|---|
| Display | 40 / 44 / 700, rounded | Главное число дня, итог сессии |
| Word | 34 → 28 → 24 → 20 / 1.2 / 650 | Испанское слово в сессии (по длине) |
| Title 1 | 28 / 34 / 700 | Заголовок раздела |
| Title 2 | 22 / 28 / 650 | Заголовок блока-героя, перевод в сессии |
| Headline | 17 / 22 / 600 | Заголовки карточек, строки списка |
| Body | 17 / 24 / 400 | Основной текст, поля ввода (≥ 16 — без зума iOS) |
| Callout | 15 / 20 / 400 | Вторичный текст, переводы в списке |
| Footnote | 13 / 18 / 500 | Подписи, легенды |
| Caption | 12 / 16 / 600 | Значки, оси графиков, интервалы |
| Overline | 11 / 14 / 700, +0.06em, uppercase | Надзаголовки («СЕГОДНЯ»), подписи вкладок |

Испанский текст размечается `lang="es"` (уже так в списке) — правильные
переносы и произношение экранного диктора.

## 5. Иконки

Свои inline-SVG (`Icon.tsx`, сейчас 11 штук) — **без библиотеки**. Стиль:
24 × 24, линия 1.75, скруглённые концы/стыки, `currentColor` — близко к SF
Symbols. Добавить: `close`, `search`, `filter`, `sort`, `tag`, `chevron-down`,
`check`, `archive`, `restore`, `edit`, `bell`, `moon`, `download`, `upload`,
`info`, `speaker` (TASK_045), `refresh`. Активная вкладка — та же иконка
с заливкой 12 % акцента под ней (как сейчас), без смены формы.

---

## 6. Поверхности (карточки)

Три вида вместо четырёх классов:

| Вид | Где | Оформление |
|---|---|---|
| **Hero** | «Сегодня» на Главной, герой Статистики, итог сессии | радиус 22, фон surface, тень `--elev-2`, внутр. отступ 20–24 |
| **Card** | блоки Статистики, плитки, просмотр карточки | радиус 16, граница 1 px, тень `--elev-1` (в тёмной — без тени), отступ 16–20 |
| **Group** | Профиль, списки | радиус 16, строки 52+ px с разделителями-вставками (iOS grouped) |

Экран сессии — **без** поверхности-рамки: слово на фоне, ответ ниже,
разделитель-волосок между ними.

---

## 7. Кнопки

- **Primary** — заливка акцентом, 52 px (крупная, CTA) / 44 px, радиус 14,
  текст 17/600. Одна на экран.
- **Secondary** — заливка `--accent-soft`, текст акцентом. Для вторых
  действий («Тренировка», «Экспорт»).
- **Tertiary** — текстовая кнопка акцентом, 44 px высота зоны.
- **Destructive** — текст `--danger` на нейтральной/мягкой заливке; заливка
  красным — только в диалоге подтверждения.
- **Icon** — 44 × 44 зона, иконка 22–24.
- **Rating** — отдельный компонент: три кнопки, мягкая семантическая заливка,
  подпись + интервал, 64 px высота.

Состояния: hover (компьютер) — затемнение 6 %; pressed — scale 0.97 + 10 %;
focus-visible — кольцо 2 px акцентом с отступом 2 px; disabled — 40 %
непрозрачности, без hover; loading — спиннер вместо иконки, ширина
сохраняется.

---

## 8. Формы

Метка над полем (Footnote 600), поле 48 px, радиус 12, фон `--surface-2`
(без рамки) → в фокусе белая поверхность + кольцо акцентом. Ошибка: красная
рамка + текст под полем + `aria-invalid`. Необязательные поля скрыты за
строками «+ Пример», «+ Заметка», «+ Теги». Основная кнопка формы —
закреплена внизу листа, над клавиатурой.

---

## 9. Навигация

- **Телефон (< 900 px):** плавающая панель-капсула (сохраняется), фон
  плотнее (0.92), 4 вкладки. Скрыта: в сессии, тренировке, при открытой
  клавиатуре, при открытом листе.
- **Заголовки:** Главная — бренд-строка (логотип + серия); остальные разделы
  — крупный заголовок 28 px, который при прокрутке сворачивается в
  компактную строку 17 px с размытым фоном.
- **Компьютер (≥ 900 px):** левая колонка навигации 240 px (логотип,
  4 раздела, серия внизу); контент — по смыслу (см. спецификации), не
  растянутая мобильная колонка.

---

## 10. Движение

| Событие | Анимация | Длительность |
|---|---|---|
| Показ ответа | ответ: opacity 0→1, translateY 8→0 | 180 мс |
| Оценка | кнопка: pressed; карточка: opacity→0, translateX −12 → новая из +12 | 100 + 160 мс |
| Прогресс | ширина полосы | 240 мс |
| Лист | translateY 100 % → 0, фон затемняется | 240 мс (вход), 200 мс (выход) |
| Тост | снизу вверх + fade | 200 мс |
| Смена раздела | fade 120 мс, без сдвигов | 120 мс |

Кривая `cubic-bezier(0.2, 0.7, 0.2, 1)` (уже `--ease`). Анимируются только
`transform` и `opacity`. При `prefers-reduced-motion: reduce` — мгновенно.

## 11. Состояния элементов

Для каждого интерактивного элемента определены: обычное, hover, нажатое,
фокус, выбранное, неактивное, загрузка, ошибка. Для экранов: загрузка
(скелетон той же формы), пусто (иллюстрация-иконка 48 px + 1 фраза + 1
действие), ошибка (баннер + «Повторить»), успех (тост 3 с или экран-итог).
Подробно — [COMPONENT_LIBRARY](COMPONENT_LIBRARY.md).
