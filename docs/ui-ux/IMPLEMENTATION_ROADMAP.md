# План реализации UI v2

**Статус: согласовано владельцем 2026-11-14 (UX_DECISIONS, Q1–Q10). Ни одна задача не начата.** Номера продолжают серию
`tasks/` (последняя — TASK_034). Каждая задача — отдельная сессия, один
коммит, проверки, запись в `PROGRESS.md`; деплой — только по решению
владельца (как в TASK_029–034). Файлы `tasks/TASK_0xx.md` создаются в момент
старта задачи, а не сейчас.

## Общие правила для всех задач

- **Слой — только UI** (`apps/web`); вне `apps/web` — только ADR-006 (TASK_038). Не меняются: `packages/engine`,
  `StudySession`, FSRS, Review Log, `EngineStore`/Dexie-схема, формат бэкапа,
  `public/sw.js` (кроме автоматической версии кэша), `apps/push-worker`,
  `packages/reminders`. Исключение — TASK_046 (read-only добавка в
  `stats.ts`, после основной серии).
- **Инварианты оболочки** (TASK_028 §7): `StudySession` — один экземпляр в
  `App`; `overview()` — только после гейта `bootstrap`; горячие клавиши сессии
  не перехватываются навигацией; черновик формы живёт в `App`.
- **Тесты:** паттерн проекта — чистые модули (`*-view.ts`, `*-flow.ts`, `nav.ts`)
  с vitest; React Testing Library не вводится. `npm test`, `tsc --noEmit` во
  всех пакетах, `npm run build`, `git diff --check` — зелёные.
- **Ручная проверка** на dev в изолированном профиле: 320 / 375 / 390 / 430 /
  768 / 1280 px, обе темы, `prefers-reduced-motion`, клавиатура; тестовые
  данные удаляются.
- **Новых зависимостей — ноль** (D-19).
- npm-кэш: `--cache` во временной директории (CLAUDE.md), если вдруг
  понадобится установка (не должна).
