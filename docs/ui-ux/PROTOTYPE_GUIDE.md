# Визуальные прототипы — как смотреть

## Что это

[`prototypes/alsavi-prototype.html`](prototypes/alsavi-prototype.html) — один
самодостаточный HTML-файл (~120 КБ): токены и компоненты
[DESIGN_SYSTEM](DESIGN_SYSTEM.md), все экраны и состояния
[SCREEN_SPECIFICATIONS](SCREEN_SPECIFICATIONS.md), переходы
[USER_FLOWS](USER_FLOWS.md). Без сети, без зависимостей, без сборки; логотип
встроен (уменьшенная копия `apps/web/public/icons/icon-192.png`).

Это **проектный материал**, а не приложение: данные — пример коллекции, к
IndexedDB, Engine и push не подключается, в сборку `apps/web` не входит.

**Почему так, а не Figma/Storybook:** в проекте нет инструментов
прототипирования, а новые зависимости не нужны (D-19). HTML на тех же токенах
показывает настоящие шрифты iOS, тёмную тему и реальные размеры, и его можно
открыть на iPhone.

## Как открыть

```bash
open docs/ui-ux/prototypes/alsavi-prototype.html
```

Или двойной щелчок в Finder. Лучше всего — Safari или Chrome на компьютере
шириной ≥ 1280 px. На iPhone: передать файл через AirDrop / «Файлы» и открыть
в Safari (режим «Интерактив», масштаб 100 %).

## Что работает в «Интерактиве»

- Вкладки нижней панели.
- Главная → «Начать повторение» → «Показать ответ» (кнопка или касание по
  слову) → оценка (нажатие + анимация ухода карточки) ×4 → итог → «На
  главную» (Главная переходит в состояние «пройдено»).
- «Трудные слова» → тренировка (3 оценки) → итог → список «Трудные».
- «Добавить слово» → лист с клавиатурой → «Добавить» → тост «Добавлено ·
  Открыть» → просмотр.
- Карточки: фильтры, «Теги» (лист), строка → просмотр → «Изменить» (лист) /
  «В архив» → диалог → список + тост «Вернуть».
- Статистика: 7 / 30 дней, «Тренировка», «Все 7».
- Push: тап по уведомлению → сессия.

## Ограничения

- Поиск, сортировка, переключатели и степпер в Профиле — статичные (показан
  вид, не поведение).
- Клавиатура iOS — нарисованная заглушка для оценки места под кнопку.
- Числа примера согласованы между экранами (12 в очереди, 41 слово / 48
  карточек, 7 трудных, 86 %), но не вычисляются.
- `prefers-reduced-motion` учитывается — анимации отключаются.

## Как обновлять

Файл — один `<style>` и один `<script>`. Экраны — функции `S.home`,
`S.session`, `S.cards`, `S.add`, `S.detail`, `S.stats`, `S.profile`, `S.lock`,
`S.dHome`, `S.dCards`; список кадров галереи — массив `GALLERY`; переходы
интерактива — объект `ACT`. Токены в начале `<style>` должны совпадать с
DESIGN_SYSTEM. После реализации TASK_035–044 прототип становится
историческим — источником истины будет приложение.
