# Дизайн-система ALSAVI v2 — токены и правила

Источник истины после реализации — `apps/web/src/styles.css` (раздел токенов).
Этот документ — спецификация для TASK_035. Существующие токены TASK_029
сохраняются по именам, где возможно; новые добавляются; таблица соответствия
— §9. Компоненты — [COMPONENT_LIBRARY](COMPONENT_LIBRARY.md).

Тёмный блок, как и сейчас, пишется дважды (`[data-theme='dark']` и
`@media (prefers-color-scheme: dark) :root:not([data-theme='light'])`);
существующий тест `theme.test.ts` проверяет их идентичность — сохранить.

## 2. Типографика

```css
--font-text: -apple-system, BlinkMacSystemFont, 'SF Pro Text', 'Segoe UI', Roboto, sans-serif;
--font-display: -apple-system, BlinkMacSystemFont, 'SF Pro Display', 'Segoe UI', Roboto, sans-serif;
--font-rounded: ui-rounded, 'SF Pro Rounded', var(--font-display);
```

| Токен (`--type-*`) | size / line-height / weight / tracking | Применение |
|---|---|---|
| `display` | 40 / 44 / 700 / −0.02em, rounded, tabular | главное число Главной, итог |
| `word-xl` | 34 / 40 / 650 / −0.01em | слово ≤ 18 символов |
| `word-l` | 28 / 34 / 650 | 19–40 символов |
| `word-m` | 24 / 30 / 600 | 41–80 символов |
| `word-s` | 20 / 27 / 600 | > 80 символов |
| `title-1` | 28 / 34 / 700 / −0.01em | заголовок раздела |
| `title-2` | 22 / 28 / 650 | заголовок героя; перевод в сессии |
| `headline` | 17 / 22 / 600 | заголовки блоков, слово в строке списка |
| `body` | 17 / 24 / 400 | текст, поля ввода |
| `callout` | 15 / 20 / 400 | вторичный текст, перевод в списке |
| `footnote` | 13 / 18 / 500 | подписи, метки полей, легенды |
| `caption` | 12 / 16 / 600 | значки, оси, интервалы |
| `overline` | 11 / 14 / 700 / +0.06em, uppercase | надзаголовки, подписи вкладок (без uppercase) |
| `kpi` | 28 / 32 / 700, rounded, tabular | числа KPI |

Правила: в одном блоке ≤ 3 ступеней; поля ввода ≥ 16 px (иначе iOS
приближает страницу); испанский — `lang="es"`; числа — `tabular-nums`;
`text-wrap: balance` для заголовков и слова в сессии, `pretty` — для абзацев;
длинные слова — `overflow-wrap: anywhere`.

## 3. Отступы и сетка

Сетка 4 px. Токены `--space-*`:

| `1` | `2` | `3` | `4` | `5` | `6` | `8` | `10` | `12` |
|---|---|---|---|---|---|---|---|---|
| 4 | 8 | 12 | 16 | 20 | 24 | 32 | 40 | 48 |

- **Поля экрана:** 16 px (< 390 px), 20 px (390–899 px); безопасные зоны —
  `max(поле, env(safe-area-inset-left/right))`.
- **Между блоками экрана:** 24 px; внутри карточки: 16 px (между строками —
  12 px).
- **Колонки:** телефон — 1; планшет (600–899) — 2 для плиток/KPI; компьютер —
  12-колоночная сетка 1160 px (gap 24) — раскладки в спецификациях.

### Брейкпойнты

| Токен | Значение | Что меняется |
|---|---|---|
| `xs` | < 360 | поля 16, слово −1 ступень, KPI в 1 колонку |
| `sm` | 360–599 | базовая телефонная раскладка |
| `md` | 600–899 | планшет: 2 колонки плиток/KPI, панель остаётся снизу |
| `lg` | ≥ 900 | левая навигация 240 px, мастер-деталь в «Карточках» |
| `xl` | ≥ 1280 | контент до 1160 px по центру правой области |

## 8. Правила адаптации

1. Mobile-first; раскладка меняется на `md` и `lg`, не плавно растягивается.
2. Ни на одной ширине ≥ 320 px нет горизонтальной прокрутки страницы
   (горизонтальная прокрутка допустима только внутри строки чипов).
3. Все фиксированные элементы учитывают `env(safe-area-inset-*)`.
4. Высоты не задаются в `vh`; полноэкранные — `100dvh` с запасным `100vh`.
5. Тексты переносятся, а не обрезаются, кроме однострочных подписей в списке
   (`text-overflow: ellipsis` + полный текст в просмотре).
6. Ориентация — портрет (манифест); на планшете/компьютере раскладка по ширине.
