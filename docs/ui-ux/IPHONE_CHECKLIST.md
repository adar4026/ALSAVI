# Проверка на iPhone — чек-лист владельца (TASK_044)

В сессии разработки устройства нет. Всё ниже проверено только в браузере
(эмуляция ширины, касаний и тем), **не на iPhone**. Этот лист — для проверки на
своём телефоне; результат впиши в `tasks/TASK_044.md` (раздел «iPhone»).

**Как поставить сборку:** `apps/web/README.md` → «Installing on a real iPhone
(PWA)»: `npm run build && npm run preview` по HTTPS в локальной сети, Safari →
«Поделиться» → «На экран „Домой“», запуск с иконки.

Отмечай: ✅ — как описано, ❌ — нет (что именно видно, лучше со скриншотом).

## 1. Оболочка и safe-area

- [ ] Сверху контент не заходит под часы / «чёлку», в обеих темах.
- [ ] **Статус-бар (I-2).** В тёмной теме (системной и выбранной в «Профиле»)
  полоса с часами тёмная, текст читается. Сейчас стоит
  `apple-mobile-web-app-status-bar-style: default`; если полоса светлая на
  тёмном фоне — это отдельная задача (`black-translucent` + отступ сверху).
- [ ] Нижняя панель не перекрывает последний элемент ни в одном разделе;
  полоса «Домой» не наезжает на кнопки (I-1).
- [ ] Компактный заголовок раздела появляется сверху при прокрутке и не
  закрывает кнопку «‹ Карточки» в просмотре слова.

## 2. Клавиатура (I-3)

- [ ] «Карточки» → «＋»: курсор в «Слово», клавиатура открыта, **кнопка
  «Добавить» видна над клавиатурой** (на маленьком экране — тоже).
- [ ] Enter «Далее» → «Перевод»; «Готово» → слово добавлено, лист остаётся,
  тост «Добавлено: … · Открыть».
- [ ] Плавающая / свёрнутая клавиатура (iPad или долгое нажатие на значок
  клавиатуры): кнопка не уходит за край.
- [ ] Пока поле в фокусе, нижняя панель навигации скрыта; после «Готово»
  возвращается.
- [ ] Поиск в «Карточках» и поля «Профиля»: страница не увеличивается
  (масштаб при фокусе).

## 3. Напоминания: push → сессия

- [ ] «Профиль» → «Напоминать о повторении»: iOS спрашивает разрешение,
  статус «Включены · следующее …».
- [ ] «Проверить уведомление» → уведомление приходит.
- [ ] **Холодный старт:** закрыть приложение, нажать уведомление → открывается
  сессия повторения, адрес без `#/review`.
- [ ] **Приложение открыто в фоне:** нажать уведомление → то же окно, сразу
  сессия (без второго окна).
- [ ] Запрет уведомлений в Настройках iOS → в «Профиле» «Уведомления
  запрещены» и инструкция.
- [ ] В Safari (не с экрана «Домой») — баннер с инструкцией «На экран
  „Домой“».

## 4. Офлайн

- [ ] После первого запуска включить авиарежим, закрыть приложение, открыть с
  иконки → Главная открывается, слова и сессия работают.
- [ ] «Профиль» → «Импорт из Anki» в авиарежиме открывает выбор файла
  (модуль импорта уже в кэше).

## 5. Восемь сценариев (USER_FLOWS)

1. [ ] Главная → «Начать повторение» — одно касание до сессии.
2. [ ] Сессия: «Показать ответ» и три оценки — в зоне большого пальца; док
   не закрывает ответ; итог «Готово!» → «На главную».
3. [ ] Новое слово — п. 2 выше; черновик переживает закрытие листа.
4. [ ] «Карточки»: поиск без ударений, фильтры, «Теги», порядок (системный
   выбор iOS), просмотр слова, «Изменить», «В архив» → «Вернуть».
5. [ ] «Трудные слова» на Главной → тренировка → «На главную».
6. [ ] «Статистика»: «В очереди» = число на Главной; «Как считается».
7. [ ] Напоминание — п. 3.
8. [ ] «Профиль»: лимит (−/+, «Сохранено»), тема, экспорт копии (файл в
   «Файлы»), восстановление.

## 6. Общее

- [ ] Тёмная и светлая темы на всех экранах читаются.
- [ ] «Уменьшить движение» (Настройки → Универсальный доступ → Движение) — нет
  анимаций листов и карточек.
- [ ] Длинное слово (например «el ayuntamiento de la ciudad») в сессии, списке и
  просмотре — без обрезки по краю экрана.
