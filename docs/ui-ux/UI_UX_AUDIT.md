**Незадокументированные или малоизвестные возможности** (есть в коде, нет в
брифе владельца):

- Импорт колод Anki `.apkg` и резервная копия/восстановление (Профиль → Данные).
- Обратная карточка (переключатель в форме) — у одного слова две карточки с независимым расписанием.
- Предупреждение о дубле при добавлении с действиями «Всё равно добавить / Открыть существующую / Исправить»; поиск нечувствителен к ударениям (`práctica` ≈ `practica`).
- Подсказки тегов одним касанием (до 12 самых частых).
- Горячие клавиши: Пробел/Enter — показать ответ / «Хорошо», 1–4 — оценки (на компьютере); подсказки скрыты на сенсорных экранах.
- Undo архивирования («Вернуть» в уведомлении).
- Черновик новой карточки переживает смену раздела; `beforeunload` и подтверждение при уходе с несохранённым редактированием.
- Новый день при открытом приложении → новая сессия; данные «сегодня» перечитываются при возврате из фона.
- Дневной лимит новых карточек (Профиль), учитывается сессией и push-снимком.
- Push: дополнительное напоминание «накопилось много слов» с порогом; проверочное уведомление; статус разрешения и подписки.
- Hash-адреса разделов и «Назад» браузера.
- **В ядре есть, в интерфейсе нет:** `deleteNote` / `deleteCard` (сознательно заменены архивом, TASK_023 §1), `rebuildCardState`, `AI Layer` (`packages/ai`, только CLI).

## 2. Сильные стороны (сохранить)

1. **Честные данные.** Ни одного фиктивного числа; пустые состояния вместо пустых графиков; определения метрик в ядре.
2. **Фокус-режим сессии.** Навигация скрыта, есть «Завершить», запись ответа блокирует повторное нажатие, ошибка сохранения не теряет карточку.
3. **Защита ввода.** Черновик между разделами, подтверждение ухода, предупреждение о дубле, undo архива.
4. **Узнаваемая основа.** Фиолетовый `#6d5df6`, светлый холодный фон `#f6f6fb`, белые поверхности с радиусом 16–22, плавающая «стеклянная» панель — это уже идентичность экосистемы Lex.
5. **Токены и две темы.** Все цвета на токенах, тёмная тема на всех экранах, без вспышки при старте.
6. **Доступность как привычка.** `aria-*` на прогрессе и кнопках, `role="alert"`, цели касания ≥ 44 px (кроме чекбокса), `prefers-reduced-motion`, фокус-кольца.
7. **Цель дня без фальшивых процентов** — прогресс как подсказка, текст — реальными числами.
8. **Обработка ошибок** везде с «Повторить», а не тихий пустой экран.
9. **PWA-надёжность**: офлайн-старт, баннер обновления без принудительной перезагрузки.

## 6. Итог

- Продукт функционально зрелый; проблемы — в **иерархии и компоновке**, а не в логике.
- Три главных узла переработки: **экран повторения** (зона большого пальца, единый язык оценок), **раздел «Карточки»** (список как основной вид, просмотр карточки, добавление отдельно), **единицы и числа** (одно определение — одно слово).
- Остальное — эволюция: шкалы типографики/отступов, библиотека компонентов, крупные заголовки разделов, компактная Главная, сгруппированный Профиль.
