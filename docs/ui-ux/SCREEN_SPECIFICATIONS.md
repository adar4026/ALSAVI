# Спецификации экранов

Размеры — для 390 × 844 (iPhone 14/15/16), если не указано иное; токены —
[DESIGN_SYSTEM](DESIGN_SYSTEM.md); компоненты —
[COMPONENT_LIBRARY](COMPONENT_LIBRARY.md); визуально —
[`prototypes/alsavi-prototype.html`](prototypes/alsavi-prototype.html).

Общие правила для всех экранов:
- Все числа — из существующих источников (указаны в таблицах «Данные»); новые
  вычисления в UI — только перегруппировка/форматирование.
- Тон текста — «ты» (решение владельца, Q6); единицы: *слово* = заметка,
  *карточка* = направление.
- Ни одна спецификация не меняет: `LearningEngine`, `StudySession`, FSRS,
  Review Log, Dexie-схему, формат бэкапа, `sw.js`, Worker, API push.

|---|---|---|

| Шапка | Главная — `HomeHeader`; разделы — `ScreenHeader` (крупный заголовок) | Заголовок раздела в контенте; бренд — в колонке |

| Скрытие навигации | сессия, тренировка, открытый лист, клавиатура (как сейчас) | только сессия/тренировка (фокус) |
| Баннер обновления | Banner info над контентом раздела (как сейчас), не в сессии | то же |
| Гейт `bootstrap` | Skeleton `home`; ошибка — ErrorState «Не удалось загрузить настройки обучения · Повторить» | то же |

Адреса: существующие `''`, `#/cards`, `#/stats`, `#/profile`, `#/review` +

`nav.ts` (чистые функции + `nav.test.ts`).

контента 24 px (`mask`), чтобы текст не «просвечивал» (I-1).

## 2. Экран повторения (сессия FSRS)

**Цель:** вспомнить и честно оценить — без отвлечений.

### Компоновка

```
┌ SessionHeader ───────────────────────────┐
│ ✕     ▬▬▬▬▬▬▬░░░░░░░░░░░░░       3 / 12  │  44 px
├──────────────────────────────────────────┤
│                                          │
│              НОВОЕ СЛОВО   (badge, опц.) │
│              el resguardo   (word-xl)    │  слово: центр верхней
│                                          │  половины, не сдвигается
│ ─────────────── (после показа) ───────── │
│          квитанция, корешок  (title-2)   │
│ ┌ inset ───────────────────────────────┐ │
│ │ ПРИМЕР                                │ │
│ │ Guarda el resguardo de la solicitud. │ │
│ └──────────────────────────────────────┘ │
│ ┌ inset ── МОЯ ЗАМЕТКА ────────────────┐ │
│                                          │
├ ActionDock (фиксирован) ─────────────────┤
│ [          Показать ответ             ]  │  до показа
│ [ Не помню ][ С трудом ][  Помню   ]     │  после показа, 64 px
│    10 мин      1 мес       2 мес         │
└──────────────────────────────────────────┘
```

### Правила
- **Слово** — `word-*` по длине (`≤18 / ≤40 / ≤80 / >80` символов),
  `text-wrap: balance`, `lang="es"`. Положение — центр верхних 45 % области
  контента; при показе ответа слово **остаётся на месте**, ответ появляется
  ниже. Если ответ длинный — область контента прокручивается, док остаётся.
- **Значок** — только «Новое слово» для `state === 'new'`. FSRS-состояния
  «изучается/на повторении/переучивается» — убрать с экрана (есть в просмотре
  карточки).
- **Показ ответа:** кнопка дока, касание по области слова, Пробел/Enter.
- **Оценки (решение владельца, D-06):** `RatingBar` с **3 кнопками** «Не
  помню · С трудом · Помню» → `again / hard / good`. «Легко» (`easy`) в UI
  нет. Интервалы — `previewIntervals` + `formatInterval` для трёх значений.
  Клавиши: 1–3 и Пробел/Enter = `good`; клавиша 4 ничего не делает
  (`HOTKEY_RATINGS` в `review-hotkeys.ts` сокращается до трёх). Ядро и
  `ReviewFlowController` не меняются; перед кодом — ADR-006.
- **Обратная связь:** нажатая кнопка 100 мс → карточка уходит влево и
  появляется следующая (160 мс); полоса прогресса анимируется. Без звуков,
  вибраций и конфетти.
- **Сохранение:** все кнопки X на время `saving` (как сейчас); при
  `state.error` — Banner error над доком «Ответ не сохранён. Попробуй ещё
  раз.» — карточка и выбор остаются.
- **Выход «✕»:** X во время `saving` (как сейчас «Завершить»); ведёт на
  Главную, ничего не записывает. `aria-label="Завершить повторение"`.
- **Шапка ALSAVI в сессии не показывается.**

### Состояния

| Состояние | Экран |
|---|---|
| loading | Skeleton `session` |
| empty (лимит) | Итог-шаблон: «На сегодня всё», «Дневной лимит новых карточек достигнут — новые вернутся завтра», «На главную» |
| empty (нечего) | «Сегодня всё повторено», «Возвращайся, когда подойдёт срок» — тот же шаблон (в т.ч. после push, сц. 7) |
| active / revealed | как выше |
| saving | кнопки X, спиннер не нужен (< 100 мс обычно) |
| error | Banner над доком |
| finished | **Итог:** бренд-знак (градиент) 56 px, «Готово!» (title-1), StatGroup: «Повторено 12 карточек», «Новых 5»; secondary «Тренировка трудных · 7 слов» (если есть); primary «На главную» |

Данные итога — только `summary.reviewed`, `summary.newReviewed` (как сейчас).
Точность сессии **не** показывается: в `summary` её нет (можно вычислить в
контроллере — решение D-12, по умолчанию нет).

### Произношение (TASK_045, после основной серии — Q3)
IconButton 🔊 справа от слова; `speechSynthesis.speak(new
SpeechSynthesisUtterance(front))`, `lang='es-ES'`; кнопка скрыта, если
`'speechSynthesis' in window` ложно или нет голоса `es`. Офлайн на iOS.
Не автопроизношение (не мешать вспоминанию).

### Адаптация
- 320–374: RatingBar 3 кнопки (≈ 93 px при 320), подписи 15/600 без
  переносов; интервал 12.
- 375–430: как спецификация.
- ≥ 600: колонка 560 px по центру, док той же ширины.
- ≥ 900: без боковой навигации (фокус-режим), подсказки клавиш видимы.

### Тренировка трудных слов
Тот же экран. Отличия: метка «Тренировка · расписание не меняется» в
`SessionHeader` (overline акцентом), значок «забыто N раз» (Badge danger) в
потоке над словом, тот же `RatingBar` с 3 кнопками, но **без интервалов**, итог-шаблон с
числами `practised / good / struggled`, списком слов с ошибками и действиями
«Повторить слова с ошибками» (primary), «Ещё раз» (secondary), «К трудным
словам» (tertiary). Логика `PracticeController` не меняется.

```
│ [# Теги ▾]  [⇅ Сначала новые ▾]   41 ▸   │  footnote: найдено
├──────────────────────────────────────────┤
│ el buzón                        ● новое  │  ListRow 64

└──────────────────────────────────────────┘
```

### Данные и логика
- Строки — `buildNoteEntries` (без изменений). Статус-хвост: `due` →
  «повторить» (accent), `learning` → «изучается» (warning), `new` → «новое»
  (neutral), `review` → «через 5 дн» (secondary text), архив → «в архиве».
- Фильтры состояния — существующие `StatusFilter`; счётчики на чипах —
  `filterEntries` по каждому статусу (чистая функция в `card-list.ts`, тест).
- Теги — лист с `collectTags` (мультивыбор, «Сбросить»).
- **Сортировка (новое, только UI):** «Сначала новые» (текущая, по
  `createdAt`), «По алфавиту» (`localeCompare('es')`), «Ближайшие повторения»
  (`nextDue`), «Чаще забываю» (сумма `lapses`). Чистая функция `sortEntries`
  в `card-list.ts` + тест. Выбор не сохраняется (или `localStorage`, как
  тема — D-13).
- «Трудные»: под строкой фильтров — Banner info «Тренировка · 8 карточек —
  расписание не меняется» с primary «Начать».
- Подпись «Найдено: N из M» — справа в строке сортировки.

### Состояния
loading — Skeleton `list`; error — Banner + «Повторить»; пусто (нет слов) —
EmptyState «Здесь будут твои слова» + primary «Добавить слово»; ничего не
найдено — EmptyState «Ничего не найдено по «…»» + secondary «Сбросить
фильтры»; архив пуст — «В архиве пусто».

### Взаимодействия
- Тап по строке → `#/cards/<noteId>` (просмотр). Строка без кнопок.
- «＋» → `#/cards/new`.
- Возврат из просмотра — позиция прокрутки и фильтры сохраняются (состояние
  `CardManager` не пересоздаётся; сейчас `seq`-ремоунт — только при входе из
  других разделов).
- Undo архива — Toast «la nevera в архиве · Вернуть» (`ArchiveFlow` без
  изменений).

### Адаптация
- ≥ 900 (`SplitView`): список 380 px слева; справа — просмотр выбранной
  карточки или форма добавления (вместо листа). Выбранная строка — S.
- 1 000+ слов: если проверка C-10 подтвердит задержку — «Показать ещё 100»
  внизу списка.

## 4. Лист «Новое слово» (и редактирование)

### Компоновка

```
┌ Sheet ───────────────────────────────────┐
│ Отмена        Новое слово                │
├──────────────────────────────────────────┤
│ Слово или фраза                          │
│ [ la práctica                         ]  │  autofocus, lang=es
│ Перевод                                  │
│ [ практика                            ]  │
│                                          │
│ ＋ Пример                                │  ListRow-кнопки, раскрываются
│ ＋ Личная заметка                        │  в TextArea
│ ＋ Теги           (+ основа)(+ глаголы)→ │  лента подсказок
│ Обратная карточка                 [  ○]  │  Switch-строка 52 px
│   перевод → слово, своё расписание       │
├ ActionDock (над клавиатурой) ────────────┤
│ [              Добавить               ]  │
└──────────────────────────────────────────┘
```

### Правила
- Контроллер — существующий `createForm` из `App` (черновик сохраняется при
  закрытии листа и переходах — как сейчас между разделами).
- Enter в «Слово» → фокус «Перевод»; Enter в «Перевод» → отправка (как сейчас
  `enterKeyHint="done"`).
- Подпись кнопки: «Добавить» / «Добавить 2 карточки» (с обратной) /
  «Сохранение…».
- После успеха: форма очищается, фокус в «Слово», Toast «Добавлено: la
  práctica · Открыть» (→ `#/cards/<id>`). Лист **не закрывается** (пакетный
  ввод); «Готово»/«Отмена»/свайп вниз — закрыть.
- Ошибки полей — под полями, фокус на первое ошибочное (как сейчас).
- Дубль — Banner warning в листе: «Похожее слово уже есть: …» + «Всё равно
  добавить» (primary), «Открыть существующее» (secondary), «Исправить»
  (tertiary) — как сейчас.
- Ошибка записи — Banner error, текст в полях остаётся.
- Закрытие с введённым текстом: черновик **сохраняется** (не спрашиваем) —
  поведение TASK_033; кнопка «Очистить» — tertiary внизу листа при непустом
  черновике.

### Редактирование
Тот же лист, заголовок «Изменить слово», кнопка «Сохранить»; без
переключателя обратной карточки (как сейчас — `alsoReverse` только при
создании); закрытие с изменениями → Dialog «Отменить изменения?» (замена
`window.confirm` TASK_033 внутри приложения; `beforeunload` остаётся).

### Адаптация
- Клавиатура iOS: док над клавиатурой через `visualViewport`
  (`resize`/`scroll`), панель навигации скрыта (лист её и так закрывает).
- ≥ 900: правая панель SplitView или окно 560 px.

## 6. Статистика

### Метрики: смысл и расчёт (только существующие данные)

| Метрика | Смысл для ученика | Расчёт (источник) |
|---|---|---|
| **Изучено слов** | Сколько слов прочно в памяти | `notes.learned` из `notes.active`: активные заметки, **все** карты которых в FSRS-состоянии `review` (`stats.ts`, TASK_031). Кольцо = learned / active |
| **Точность ответов** | Как часто вспоминаю | `answers.successful / answers.total` × 100, округление; успешный = `hard/good/easy` (весь журнал, включая архив). `—` при 0 ответов |
| **Серия** | Дней подряд с занятиями | `streak.current`; деталь — «сегодня засчитан» / «сегодня ещё нет ответов»; «рекорд N» при `longest > current` |
| **Сегодня в очереди** *(замена «К повторению»)* | Сколько карточек ждёт сегодня — **то же число, что на Главной** | `session.overview().total` (+ `newCount/learningCount/reviewCount` в детали). `StatsScreen` получает `overview` от `App` (UI-проводка, только чтение, после гейта `bootstrap`) |
| Повторений за период | Объём работы | `activity.last7/last30.total` |
| Дней с занятиями | Регулярность | `activeDays` из `days` |
| В среднем за день занятий | Нагрузка в учебный день | `total / activeDays` (`activityDigest`) |
| По дням | История | `window.days[]` (таблица) |
| Карточки по стадиям | Где находятся карточки | `cards.new / learning / dueReview + waiting` (стадия «изучены» = `review`), % от `cards.active`; архивные — в подписи |
| Трудные слова | Что требует внимания | `difficult.total`, топ-3 из `difficult.words` (по сумме lapses) |
| Сегодня (опц. строка в «Активности») | Как прошёл день | `today.reviews`, `today.successful`, `today.again` → «Сегодня 23 ответа · 87 % верно» |

**Не показываются в этой серии** (TASK_046 — после основной серии, Q5): время обучения (`Review` без
длительности), динамика точности по неделям/месяцам и «месячная динамика»
дольше 30 дней (Review Log позволяет, но `getLearningStats()` отдаёт только
7/30 — нужна read-only добавка в `stats.ts` с тестами ядра), прогноз нагрузки,
retention по периодам.
